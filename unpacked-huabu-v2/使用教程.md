# BatchRefiner 无限画布 · 新手试用教程

这是一份零基础教程，跟着做就能用「AI Agent + RunningHub 工作流」在画布上出图。

---

## 一、开始前：先配好 3 样东西

打开网页后，点**右上角的「API 设置」**，一共要填 3 处（密钥只保存在你自己的浏览器里，不会发给 AI 模型）：

### 1. AI 对话平台（Agent 的大脑）
- 选一个平台，填写 **API Key**（Base URL 一般平台会预填）；
- 在该平台的**文本模型**里确认有模型可选（推荐 GLM-5.3-Flash 这类对话模型）；
- 图片/视频生成平台也要填好密钥（Agent 生成图片时用的是这里的图片模型）。

### 2. RunningHub 工作流（可选，想用工作流放大/出图才需要）
- 在「API 设置」里找到 **RunningHub 工作流** 区域：
  - **Base URL**：填 `https://www.runninghub.cn`；
  - **API Key**：在 RunningHub 官网个人中心生成；
  - 点**添加工作流**：起个名字（如 `高清放大`），**workflowId** 填 RunningHub 工作页地址栏里 `/run/workflow/` 后面的那串数字；
- 不填参数也能跑（用工作流默认值）；想改参数就点**添加参数**：
  - **文本参数**：填 nodeId、fieldName 和默认值；
  - **图片参数**：只填 nodeId 和 fieldName，运行时会自动吃上游连进来的图。

### 3.（推荐）导入工作流完整字段
导入后 Agent 才知道这个工作流有哪些参数（比如有没有 4K 选项）：
- 点屏幕左下角的 **RH** 按钮；
- 目标工作流选你刚建的；
- 粘贴工作流 JSON（RunningHub/ComfyUI 导出的 API 格式），点**解析并保存到本地设置**；
- 按提示**刷新页面**生效。

## 二、AI Agent 怎么用（最常用）

1. 点屏幕上的**机器人图标**，打开 Agent 面板；
2. 顶部工具栏选好 **API** 平台和**模型**（选文本/对话模型）；
3. 在输入框直接说人话，按 **Ctrl+Enter**（Mac 是 ⌘+Enter）或点 ➤ 发送。

**直接抄这些例子：**

| 你输入 | Agent 会做什么 |
|---|---|
| `生成一只狗` | 创建图片节点并生成 |
| `先生成一只狗，完成后在下游加一个节点，在狗旁边加一只猫` | 生成狗 → 等出图 → 自动建下游节点并连线 → 生成狗+猫 → 全部成功才报完成 |
| `把图片节点1 的清晰度改成 2K` | 只修改你点名的节点，不新建 |
| `用 16:9、2K 生成一只猫` | 按你给的参数生成 |

**看进度：** 回复里的「思考过程」会逐轮展开，比如：
```
第1轮 createNode：创建节点 dog（generate-node-xxx）
第2轮 runNode：提交运行 dog
第3轮 waitFor：等待 dog → success
第4轮 createNode：创建节点 dogCat（generate-node-yyy）
…
第8轮 finish：任务完成
```
每一轮都是真实执行后的结果，不是模型瞎说的。

**几个好习惯：**
- 想改已有节点，就用它的名字（图片节点1、文本节点2）；不点名它就建新节点；
- 说「默认尺寸/默认参数」就用节点默认值，Agent 不会乱编参数；
- Agent 拿不准会**反问你**（比如画布上有两张图你说"改那张图"），直接回复它的消息就能继续当前任务；
- 生成失败会自动重试 1 次；再失败它会停下来告诉你原因，不会假装成功；
- 任务运行中发送按钮会变灰，等它跑完再发下一条；「清空」可重置对话。

## 三、RunningHub 工作流怎么用

### 手动运行
1. 画布的添加节点菜单里选 **RunningHub**，放一个节点；
2. 先放一个**图片节点**（或用 Agent 生成一张图）作为输入，把它的输出**连线**到 RunningHub 节点；
3. 展开 RunningHub 节点，在下拉框选工作流，点**运行**；
4. 运行期间显示"运行中..."，成功后图片直接出现在节点上，还会自动生成"结果图片"节点。

### 让 Agent 帮你跑（推荐）
输入类似：
```
把输入图用 高清放大 放大到 4K
```
Agent 会自动：查工作流 → 建节点 → 绑定你的图 → 提交任务 → 等结果 → 汇报。
- 如果这个工作流没有 4K 参数，它会如实告诉你，不会乱填；
- 如果必填的输入图没连，它会先要求绑定，不会空跑。

### 任务状态与恢复
- 每次提交都会保存任务 ID；**中途刷新页面也不怕**，重新打开后系统会按任务 ID 自动查一次结果；
- 结果没出来时，也可以在 Agent 里说"恢复查询 upscale 节点的任务"；
- 想取消任务，可以跟 Agent 说"取消 upscale 的任务"。

## 四、常见问题

| 现象 | 解决 |
|---|---|
| ❌ 请先在「API 设置」选择平台并填写 API 密钥 | 去右上角 API 设置填 Key |
| ❌ 当前平台没有文本模型 | 在该平台里添加文本模型，再到 Agent 面板重选 |
| 生成一直失败 | 检查对应平台的 Key 和模型名；失败会自动重试 1 次 |
| RunningHub 提示"必填媒体字段缺失" | 先把上游图片连线到 RunningHub 节点，再运行 |
| Agent 说工作流没有某参数 | 正常。说明该工作流字段里没有，需要的话去 RunningHub 调整工作流 |
| RH 导入字段后没生效 | 保存后需要刷新页面 |
| 页面刷新后 RunningHub 任务还在跑吗 | 在跑。打开页面后系统按任务 ID 自动恢复查询，结果会补写到节点 |

## 五、安全说明

- 所有 API Key 只存在你浏览器本地（localStorage），发给 RunningHub / 模型平台的是请求本身；
- Agent 的对话上下文里只有脱敏后的信息（工作流 ID 打码、密钥与访问密码不出现）；
- 出错信息也会自动隐去密钥，放心截图求助。
