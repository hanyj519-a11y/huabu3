# 图片节点生成历史与主图切换

## 目标

图片节点多次生成后，保留所有生成结果，并允许用户在节点内查看、切换历史主图。当前主图继续作为节点输出，连接到下游的图片也随选择同步变化。

## 交互

- 图片节点存在多个生成结果时，在图片预览右上角显示历史入口标记。
- 图片节点展开后，二级菜单提供历史折叠按钮。
- 点击历史按钮，在二级菜单下方展开向下的三级历史面板。
- 三级面板以缩略图展示 `outputImages`，当前 `image` 标记为当前主图。
- 点击任意缩略图后，将其写入 `image`，关闭历史面板，并立即更新节点预览。
- 用户可以再次打开历史面板切换主图；提示词、模型、尺寸、比例和张数设置保持可编辑。

## 数据流

1. 每次生成成功时，将新结果追加到 `outputImages`，并将最新结果写入 `image`。
2. 历史面板只读取 `outputImages`，不复制图片文件或创建新的持久化结构。
3. 选择历史项时，通过现有 `updateNode` 更新 `image`，下游继续读取节点当前 `image`。
4. 生成失败不新增历史项，也不改变当前主图。

## 实现边界

- 复用现有图片节点的展开状态、弹层关闭逻辑和缩略图组件样式。
- 历史入口只在有至少两个结果时显示，单张结果不增加额外控件。
- 切换主图不改变 `outputImages` 顺序，不删除历史结果。
- 保留现有上传/替换、放大、下载和继续生成行为。
- 不改变视频节点、Agent 面板或通用模型请求协议。

## 测试

- 验证图片节点历史入口和三级面板结构存在。
- 验证历史项使用 `outputImages` 渲染，并能将选中项写入 `image`。
- 验证选择历史项后关闭三级面板。
- 验证生成成功追加历史结果，生成失败不改变历史。
- 运行完整 Node 测试、JavaScript 语法检查、CSS 资源检查。
